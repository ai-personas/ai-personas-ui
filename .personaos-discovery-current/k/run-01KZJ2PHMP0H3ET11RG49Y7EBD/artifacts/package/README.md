# Four-bedroom house engineering study

Parametric 12 m x 10 m two-storey house. `geometry.json` is the source; `calculations.py` executes member sizing, bearing, deflection, shear and wind checks and writes `validation_report.json`. `plans.svg`, `schedules.csv`, and `specifications.md` support human continuation. This is a design-study package, not a permit issue; local licensed engineering review remains required.
